The project repository is https://github.com/doctor-ew/yata. Historical issue links remain in the original repository. Imported reports retain their original test observations and may use the previous directory layout. LICENSE preserves the upstream MIT notice. Source attribution remains in ATTRIBUTION.md.

The hosted endpoints remain https://doctorew.com/tv/ and https://doctorew.com/arcade/. Shared catalog state is not modified by repository migration. APKs are release attachments rather than tracked source files. Runtime downloads and privately supplied game files remain ignored.
