# Additional classic cartoons

## Scope

Add checked recordings of Mister T and full combined Frankenstein Jr. and The Impossibles programs. Retain existing Hong Kong Phooey, Inch High Private Eye, Birdman, and Jonny Quest entries. Do not duplicate bundled programs as separate shows.

## Data

Nine Mister T recordings retain embedded television commercials and explicitly label them. YATA's optional break setting cannot remove advertisements already encoded in a recording. Source sequence is retained without inventing season-relative episode order.

Eighteen combined Frankenstein Jr. and The Impossibles programs retain collection order. A short extra is excluded. The public catalog adds two shows and 27 episode/source entries. Existing source definitions remain unchanged.

## Verification

Each new source must pass a bounded HTTP video-range request before inclusion. Tests check discovery-to-built-catalog coverage and preserve existing entries. Publication requires a reviewed diff against the current shared revision. Range checks establish current reachability, not complete decoding or future availability.
