# Channel snow correction — 0.8.17

## Change

The user rejected the 0.8.16 effect after watching it in the application. It used a translated repeating SVG texture and a fade-out. Version 0.8.17 replaces that transition with an original 480 × 270 monochrome animated GIF: 12 independently generated frames at 30 frames per second, looping while visible. The transition cuts directly back to playback. The existing duration, static toggle and accessibility suppression remain in effect.

The asset is preloaded and shared by web and the Capacitor packages. Both local and published servers use image/gif. `scripts/generate-channel-snow.py` reproduces the bundled asset using a deterministic noise generator and ffmpeg. No footage, sound or code was copied from the references.
