# Classic arcade candidates

These are recommendations to investigate, not installed titles or verified playable sources. Rights, source provenance, emulator compatibility and controls must be checked before publication.

| Platform | Candidates |
| --- | --- |
| Atari | Adventure, Yars’ Revenge, Asteroids, Centipede, Missile Command, Breakout |
| ColecoVision | Zaxxon, Lady Bug, Venture, Mouse Trap, Smurf: Rescue in Gargamel’s Castle |
| Commodore 64 | Impossible Mission, Boulder Dash, Jumpman, Paradroid, Summer Games, Winter Games, California Games, Pitstop II |
| Arcade | Pac-Man, Galaga, Dig Dug, Xevious, Mappy, Bosconian |

Prioritize Adventure, Yars’ Revenge, Centipede, Galaga, Zaxxon, Impossible Mission and Boulder Dash. No game files were acquired for this recommendation pass.

The current curated shelf has 12 classic entries: eight curated Atari/arcade titles plus four additional arcade/NES preservation ports. C64 currently uses local-file loading; ColecoVision needs compatible runtime/firmware support before games can be offered through the local slot.

Sources: [Atari 50](https://atari.com/products/atari-50th-the-anniversary-celebration), [Atari arcade products](https://atari.com/collections/arcade-machines), [THEC64 game list](https://retrogames.biz/products/thec64/), [ColecoVision FAQ](https://www.colecovision.dk/PDF/ColecoVision-faq-4.1.pdf), [Bandai Namco classics](https://www.bandai.com/pac-man-connect-n-play).
