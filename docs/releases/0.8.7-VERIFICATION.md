# YATA 0.8.7 verification

## Scope

Global catalog episode/story-title search and seven sourced US series ratings. Shared web/native JavaScript, Android version 0.8.7 / version code 18. No new paid AWS retrieval resources or public transcript index were provisioned.

## Evidence

- Full Node suite: 252 tests passed; repository syntax checks passed.
- Focused rating, episode-search and release-note suite: 13 tests passed after calendar-date validation was tightened.
- Chrome exercised the authoritative 255-show catalog: TV-Y7/TV-MA card labels, publisher-reference link, explicit unknown rating, Grimm compilation label, cross-show title search, channel-filter updates and checked Archive source playback selection.
- Independent adversarial review approved the limited search/rating scope, with no blockers. Its nonblocking calendar-date warning was repaired and covered by a rejection test.
- Android debug build passed. ADB installed 0.8.7 over Wi-Fi and package inspection confirmed version code 18. Physical fullscreen/rotation remained unverified: the device's notification/lock surface prevented responsive WebView inspection. Do not count the install as a playback test.
- iOS project receives the shared frontend assets. No iOS archive, TestFlight upload or physical iPhone verification was performed in this increment.

## Rating provenance

Disney series pages list TV-Y7 for original Gargoyles (1994), Adventures of the Gummi Bears (1985), Rescue Rangers (1989), Darkwing Duck (1991) and X-Men (1992). Adult Swim series pages display TV-MA for Aqua Teen Hunger Force and The Venture Bros. The feed retains US jurisdiction, series scope, publisher URL and verification date. Archived edits, compilations and breaks are not individually classified. Missing evidence remains Unrated; these labels do not enforce parental controls.

## Search and retrieval boundaries

Search uses show and episode/story titles, not plot descriptions, captions or scripts. It renders at most 50 results and resolves current catalog identities and checked sources at click time. Enrichment and semantic retrieval are described in the architecture proposal; they have not shipped. IMDb public-app licensing remains unresolved; TMDB/TheTVDB require appropriate API access and terms review before ingestion.
