# YATA 0.8.10 verification

## Catalog additions

The extended feed contains 258 shows, 12,084 entries and 12,398 sources. It starts from the previous authoritative 255-show snapshot, preserving every prior show, episode and source value. Added: Punky Brewster (1984), 86 entries including five labelled paired presentations (two are double-length); Clarissa Explains It All (1991), 54 episodes; Ramona (1988), five episodes. No videos are rehosted.

All 140 added Archive endpoints passed GET byte-range checks. Representative Punky and Clarissa files report H.264 video/AAC audio. Five Ramona uploads returned public, embeddable metadata and full-episode durations. Five other candidate Ramona uploads could not be verified through the sign-in challenge and were excluded. These checks do not establish full decoding, content permissions or future availability. Original-series TVmaze metadata and artwork have source references in data/library-art.json.

## Compatibility

The extended manifest is data/published-catalog-v2-manifest.json with a bounded 512-show reader. The original data/published-catalog-manifest.json remains the unchanged 255-show compatibility edition. Older clients through 0.8.9 continue using that edition; they require an app update for the new shows. New clients fall back to the original feed only if the extended pointer is absent. Hash checks, immutable snapshots and conditional publication remain unchanged. Both native reader allowlists explicitly admit the two manifest paths; other URL restrictions remain intact.

## Validation

The application suite passed 275 tests; syntax checks and Android debug build passed. Live Chrome displayed all three new shows. Artwork was checked after scrolling lazy-loaded cards into view. Android version 0.8.10/code 21 bundles the new 258-show snapshot. No ADB device was connected at final installation check, so this APK has not been installed on the phone. Swift reader source updated; iOS remains uncompiled.

The existing retrieval corpus is unchanged at 86 summaries for Gargoyles and Street Hawk. This content release does not add plot-search evidence for the three new shows.
