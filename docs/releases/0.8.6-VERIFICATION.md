## Deployment and Android

The website and Arcade shell were published. Fifteen changed shell/feed files were uploaded in dependency/coordinator/HTML order with versioned object receipts and conditional writes. No game binaries or private packages were changed by that shell release. Live source hashes matched the tested files. Public-access blocks remained enabled.

Android 0.8.6 (version code 17) built successfully and was installed over Wi-Fi ADB. The running app reported the 255-entry card collection, 253 artwork records, 163 game metadata entries and the new fullscreen control. A subsequent physical fullscreen automation session became unresponsive; it was stopped without claiming success. Rotation preferences remained at their original values. Physical fullscreen follow-up and physical iPhone verification remain outstanding.
