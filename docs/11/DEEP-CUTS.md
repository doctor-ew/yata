# Cartoon Express deep cuts and adventure television

## Audience and scope

Implements [issue 11](https://github.com/doctor-ew/floating-browser/issues/11). The requested editorial direction is an early-1980s childhood: obscure Hanna-Barbera cartoons associated with the USA Cartoon Express era, and adventure television in the spirit of The Greatest American Hero, Manimal, Knight Rider and The Dukes of Hazzard. Prioritize these deep cuts over expanding mainstream sitcom cartoons. Existing shows remain available.

This release adds 159 media entries across six cartoons and five adventure shows. Misfits of Science and Otherworld are explicitly labeled 1985 exceptions. This is not a reconstruction of a specific dated USA broadcast schedule.

## Interpretation and exclusions

- **Wizards and Warriors (1983):** English eight-episode collection with explicit season/episode numbering.
- **The Powers of Matthew Star:** English 22-entry source sequence; source episode 22 is labeled Starr Knight pilot. Source numbering is preserved, not independently reconstructed broadcast order.
- **Misfits of Science (1985):** English 16-entry collection; the approximately 92-minute pilot is one intact media entry. This show dates from 1985.
- **Otherworld (1985):** English eight-entry collection; explicit Episode numbers are retained with season zero. This show dates from 1985.
- **Whiz Kids:** Mixed-language collection: retain only the EN - VHS - Whiz Kids (1 - 18)/Syndicated (1-18)/272p/ directory and explicit Whiz Kids season/episode filenames. Exclude French material, alternate encodes, crossovers and cut scenes. Language is indicated by the chosen directory rather than independently verified audio.
- **Butch Cassidy and the Sundance Kids:** Collection contains 13 E-numbered stories. Derivative and filename aliases collapse by source number. Language metadata is absent; season zero denotes source sequence.
- **Clue Club:** Collection contains 16 explicitly numbered season 1 stories. Language metadata is absent.
- **Goober and the Ghost Chasers:** Collection contains 15 E-numbered stories: 1–6 and 8–16. Episode 7 is missing. Language metadata is absent; the Italian collection was not merged.
- **Wheelie and the Chopper Bunch:** English collection contains 13 EP-numbered three-story programs. Keep each bundle intact; season zero denotes source program sequence.
- **The Funky Phantom:** English collection contains 17 E-numbered stories, labeled by the uploader as AI-enhanced video. Season zero denotes source sequence.
- **Inch High, Private Eye:** English collection contains 13 explicitly Episode-numbered stories. Season zero denotes source sequence.

- The Roman Holidays candidate had no compatible public MP4 episodes. No clear Buford Files or Galloping Ghost cartoon collection was found in this bounded search; unrelated puppet shows, serials and arcade recordings were excluded. These are discovery gaps, not claims that no sources exist elsewhere.
- Tales of the Gold Monkey candidates need deliberate episode mapping and subtitle review before import. No automatic inclusion in this release.
- Unset source language metadata remains unknown; a compatible MP4 endpoint does not establish English audio.

## Acceptance and verification

- All 45 tests and syntax checks pass. Tests cover additive import from older catalogs, genre membership, schedule eligibility, source numbering, the missing Goober episode, Wheelie story bundles, Misfits' long pilot, the Whiz Kids English directory restriction and repeated-import deduplication.
- First and last retained files from all eleven additions returned HTTP 206, video/mp4 and an MP4 signature for 32-byte range requests. Evidence is stored alongside the reviewed show records. Full browser decoding and audio-language verification were not performed.
- Partial action refreshes preserve earlier records, reject unknown show identifiers and reject empty refreshed shows before replacing the pack. Unselected shows do not trigger fresh network searches.
- Existing sources and user settings are preserved. A content revision triggers additive installation. Provider video files are not mirrored in the static release. Source availability does not establish redistribution rights or future playback.
