# Apple beta delivery

## Status

Prepared on 2026-11-17 on branch `feature/apple-testflight`. No upload or TestFlight distribution has occurred. Both projects use bundle identifier `com.doctorew.yata`; the archive helper takes the marketing version from `mobile/package.json` and requires an explicit build number. Build numbers must be checked against App Store Connect before uploading.

## Targets

- iOS: `ios/App/App.xcodeproj`, scheme `App`. Reuses the existing Capacitor interface. The `yata` custom URL scheme connects to the existing shared-link handler. Android background audio remains Android-only.
- tvOS: `tvos/YATA.xcodeproj`, scheme `YATA`. Native SwiftUI library, show search, episode selection and AVKit playback of checked HTTPS Archive sources. Unavailable or unsupported providers remain visible and cannot launch. YouTube playback, scheduled channels, saved queues, buddy chat and Arcade are not implemented. This is a first native foundation, not feature parity with iOS.

`tvos/prepare.mjs` copies the mobile build's published catalog only after checking its content hash. The app verifies the bundled snapshot and remote updates independently. It does not publish catalogs or bundle video. Licenses and attribution are bundled and accessible from About. Icons are reproducible typographic artwork generated by `tvos/make-icons.swift`.

## Archive and upload

Install mobile dependencies with `npm ci` from `mobile`. The executable helper is `mobile/apple-release.mjs`. Supply `--platform ios` or `--platform tvos`, an unused `--build NUMBER`, and `--team TEAMID`. The helper builds assets, syncs the selected platform, and archives with automatic provisioning. Add `--upload` to export to App Store Connect. Use `--unsigned` instead of a team only for compile validation; unsigned archives cannot be uploaded.

An authenticated Apple Developer Program team, signing certificates/profiles and an App Store Connect app record with both platforms are required. Local inspection found no configured Xcode account, valid code-signing identity, or standard App Store Connect private-key directory. User sign-in/team selection is pending. No passwords or signing credentials are stored in this repository.

After upload, check Apple's processing result, export-compliance questions, required beta metadata and tester group. External testers may require beta review. Internal/external distribution and Apple TV feature scope were requested from the user and remain unanswered.

Apple references: [upload builds](https://developer.apple.com/help/app-store-connect/manage-builds/upload-builds), [add platforms](https://developer.apple.com/help/app-store-connect/create-an-app-record/add-platforms), [TestFlight](https://developer.apple.com/testflight/). Capacitor's supported targets are documented in [environment setup](https://capacitorjs.com/docs/getting-started/environment-setup).
