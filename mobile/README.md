# YATA mobile

## Status

Android local test build, with an iOS project prepared from the same web interface. No app-store publication is configured. Android uses API 36 with a minimum API 24. The current Mac has command-line Android tools and JDK 21; full Xcode is not installed, so the iOS project has not been compiled or tested.

The app bundles the TV interface, real artwork and an integrity-checked catalog snapshot. Public catalog updates use a narrowly scoped native reader. A failed update falls back to the bundled snapshot. Video requires an internet connection and streams directly from its provider. Personal preferences remain on this device; they do not sync with the website.

Archive and YouTube playback, touch Konami controls, a matching TVmaze episode description, discovery of an actual autogenerated subtitle track, and the CC toggle have been tested in an Android 16 emulator. Provider availability and caption coverage vary. The web page may identify a companion subtitle file but fail to fetch it when the provider omits cross-origin headers; the native app's limited subtitle reader handles that case. Captions are not generated by YATA.

Arcade opens the hosted arcade in a browser tab in this build; games are not bundled. Long-press the YATA logo to reveal touch controls for the Konami sequence. AI channel creation opens the website because its browser-verification flow has not been integrated into the native app. A channel created on the website is stored separately from app preferences.

## Build

From this directory:

```sh
npm ci
npm run android:build
```

Set `JAVA_HOME` to a JDK 21 installation and `ANDROID_HOME` to an Android SDK containing the platform/build packages required by `android/variables.gradle`. `build.mjs` reads the current public catalog and checks its SHA-256 before bundling it. It does not bundle video files, credentials, APK backups or Arcade runtimes.

The generated APK is copied to `artifacts/YATA-0.6.0-android-debug.apk`. The Gradle output remains `android/app/build/outputs/apk/debug/app-debug.apk`. It is signed with the local Android debug key for sideload testing. Connect one Android device with USB debugging enabled, authorize the Mac, and run from this directory:

```sh
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

To inspect the iOS project after installing full Xcode:

```sh
npm run sync
npm run ios
```

Choose a signing team in Xcode before installing on a physical iPhone. iOS compilation, simulator playback and device signing remain unverified.

## Native boundary

The `YataCatalog` bridge accepts only the public manifest, content-addressed catalog paths and HTTPS Archive subtitle URLs. Catalog responses remain raw UTF-8 so the existing integrity check still applies. Caption reads are limited to one MB; catalog reads to eight MB. It is not a generic HTTP proxy. External links open through Capacitor Browser. Android Back closes overlays or navigates within the app; at the watch root it minimizes the app. Android keeps the screen awake while the app is visible.

Capacitor and the App/Browser plugins are MIT licensed. The repository's MIT license and existing media/artwork attribution remain applicable; see `../ATTRIBUTION.md`. TVmaze metadata remains attributed under CC BY-SA 4.0.

## Android automatic playback and navigation (0.3.0)

Archive video automatically hands audio to an Android Media3 foreground service when the app backgrounds or the screen turns off. Reopening the app automatically returns to video at the current queued item's position. A pause made with lock-screen or headset controls remains paused when returning to video. There is no background-playback button. Native lifecycle callbacks perform the handoff before WebView timers are suspended. YouTube remains in its visible player and pauses in the background.

The background queue contains up to 50 consecutive Archive items from the active show or station, including configured commercial breaks. It stops before a YouTube or other unsupported source. This is a bounded queue, not an indefinitely refreshed station.

The app uses Watch, Guide and Library in a single bottom navigation bar. Watch has a channel selector and core playback controls. More contains sharing, secondary playback actions, channel settings, mix/remix and creator credits. A local fragment-routing handler keeps these tabs in the bundled app instead of loading the asset server's directory fallback.

Episode sharing uses a public episode URL with an optional timestamp. Channel / playlist sharing includes the current show or station settings, selected shows, shuffle seed and clock; the receiver explicitly previews and accepts it. A different catalog revision can change available programs. Open in Android app transfers the shared lineup using YATA's custom URL scheme. YATA website shares the public site link; Android installer shares a private-cache copy of the installed signed test APK. No APK is uploaded automatically.

The Arcade is absent from normal navigation until unlocked. Long-press the YATA logo to reveal touch controls, then enter the Konami sequence. There is no visible Arcade-help button. The unlocked channel opens the hosted arcade in a browser tab.

Media3 1.11.1 is Apache-2.0 licensed; Capacitor Share is MIT licensed. Notices are bundled in tv/licenses. Automatic background playback is Android-only; the iOS project remains uncompiled and untested.

### Vintage rooms (0.4.0)

Fresh WebView launches choose a different room finish from the previous launch. Resuming the app or switching views keeps the current finish. More → Appearance provides the finish selector and a pin checkbox. The independent decal selector supports Autobots, Decepticons, Cobra, a random selection, or none. Preferences remain on the device. CSS draws the five room textures; bundled source insignia and source credits are in `decor/`. No remote image request is required at runtime.

### Typography and surfaces (0.5.0)

The app and website share locally bundled Cabin text and Fraunces display fonts. Their SIL Open Font License notices ship in `assets/fonts/`. The remote uses grouped physical controls, while mobile navigation uses a small amber position light. Known show prefixes and season/episode labels are shortened for display; the original title remains in expandable source details. The catalog and provider titles are not changed.

### Tuning snow (0.6.0)

Standby reads “It’s probably a rerun.” Source loading and buffering display animated monochrome TV snow. Picture readiness, pause, playback errors, and a 12-second recovery timeout dismiss the overlay. Reduced-motion settings keep the noise still. CRT scanlines and tuning static default to on; saved user choices remain respected. Provider controls remain available when playback needs a tap.
